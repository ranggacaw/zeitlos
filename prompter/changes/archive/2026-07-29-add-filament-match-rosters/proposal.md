# Change: Add Filament match rosters

## Why
Admins can now manage basic players and matches in Filament, but match rosters and copyable WhatsApp roster text still depend on the legacy Inertia admin workflow. Moving this workflow into Filament continues the CMS replacement while preserving the existing domain models and public PWA behavior.

## What Changes
- Add a Filament match roster management page for each `FootballMatch`.
- Allow admins to add roster entries for existing players or guest names, with goalkeeper/player grouping.
- Allow admins to remove roster entries from the Filament roster workflow.
- Display copyable WhatsApp roster text generated by `App\Team\WhatsAppRosterText`.
- Add navigation from the Filament match list and match edit page to roster management.
- Keep the legacy Inertia roster routes in place until the final replacement increment.
